Лабораторна робота №1

Тема: Імплементація та маніпуляції основними типами та структурами даних у Python.

Виконала: студентка групи БІКСб-2-25-40д, Бублик Надія

Опис
У цій лабораторній роботі досліджуються особливості роботи з вбудованими структурами даних Python та їхня алгоритмічна складність. Кожне завдання винесено в окремий файл:
- `task1.py` — робота зі списками (індексація, зрізи, мутації in-place).
- `task2.py` — робота з кортежами (розпакування, агрегація, перевірка іммутабельності).
- `task3.py` — робота зі словниками (підрахунок частот слів, нормалізація, dict comprehension).
- `task4.py` — робота з множинами (перетин, об'єднання, перевірка на підмножину).
- `task5.py` — експериментальне порівняння часу виконання операцій (List vs Set vs Dict).

 Інструкція із запуску
Проєкт використовує виключно вбудовані модулі Python стандартної бібліотеки. Зовнішні залежності відсутні (файл `requirements.txt` порожній).
